## 📏 命名与组织约定

- **一级目录**：按平台/来源编号归类（`00` ~ `12`）
- **Codeforces**：`{Round编号} {div级别} {日期}` —— 如 `1000 div2 01.22`
- **AtCoder**：`{日期} {赛事编号}` —— 如 `24.01.20 ABC337`
- **VP**：`{日期} {年份} {赛事全名}` —— 如 `11.24 2024 ICPC 沈阳区域赛`
- **单场文件**：`A.cpp`、`B.cpp`、`C.cpp`… 按题号命名

## 🛠️ 本地编译运行

> 需要已安装 `g++`（建议 C++17 及以上）。

### Windows (PowerShell)

```powershell
cd "E:\XCPC\00 Codeforces\1000 div2 01.22"
g++ -std=c++17 -O2 -pipe A.cpp -o A.exe
.\A.exe
```

### Linux / WSL

```bash
cd "00 Codeforces/1000 div2 01.22"
g++ -std=c++17 -O2 -pipe A.cpp -o A
./A
```
